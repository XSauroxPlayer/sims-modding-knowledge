# Lyralei: spawning any prop with NRaas DebugEnabler (TS3)

## Key facts
- NRaas DebugEnabler: click the ground > Debug Enabler... > Options > "Create Object", type the prop name
  (e.g. `CoffeeCup`). Works for props that are not in Buy mode. Name list: `1401-list-of-prop-names.md`.
- A quick in-game check that a prop name resolves before using it in script or Jazz.
