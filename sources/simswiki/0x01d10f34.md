# TS3 MLOD (0x01D10F34)

RCOL chunk found in MLOD and MODL resources; maps each mesh group to VRTF/VBUF/IBUF/MATD(or MTST)/SKIN.

## Layout (version 0x201)
Per group: `subset_bytes`, `NameHash` (FNV32 of group name), Material (MATD or MTST private index), VRTF, VBUF, IBUF
indices, `Flags = PrimitiveType | (MeshFlags << 8)`, StreamOffset (bytes into VBUF), StartVertex 0, StartIndex,
MinVertexIndex 0, VertexCount, PrimitiveCount, bounding box (6 floats), SKIN index, bone hash list, then a special
MATD index "that only has UVScale/UVOffset/PosScale/PosOffset and no ShaderName", then geometry states
`{name hash, VBUF start, IBUF start*3, VBUF count, IBUF count}`. Version > 0x201 adds ParentNameHash (always 0),
mirror plane normal (3 floats) + offset.

- Primitive types: 0 PointList ... 3 TriangleList ... 7 DisplayList.
- Mesh flags: 0x1 BasinInterior, 0x2 HDExteriorLit, 0x4 PortalSide, **0x8 DropShadow**, 0x10 ShadowCaster,
  0x20 Foundation, 0x40 Pickable.

## Geometry states
- `GameObject.SetGeometryState(string)` -> `ScriptCore.World.ObjectSetGeometryVisibilityState`; name FNV32-hashed and
  matched per group.
- A state name not present in a group makes that whole group visible; a "zero" state (all offsets/counts 0) hides the
  group (garden sprinkler `domeOff`/`domeOn`). States affect only their own group.
- Unexplained case: guitar has `guitarOnly`/`standOnly` but code uses `guitarAndStand` (consistent with the "unknown
  state shows everything" theory).
- **Agrees with measurements on EA game files by XSauroxPlayer** (FNV32 of the lowercase name, `empty` = C7EE8594, EA hides with
  a 0-primitive state, a mesh without the state draws whole).

## Relevance
- The DropShadow mesh flag is probably how the ground-shadow quad of cloned objects is marked (not verified; see
  `sources/gardenofshadows/`).
