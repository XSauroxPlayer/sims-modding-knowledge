# TS3 Jazz binary (0x02D5DF13) - chunk layout

Raw wikitext: https://simswiki.info/index.php?title=Sims_3:0x02D5DF13&action=raw
Text syntax and script usage: `topics/jazz.md`.

## Container
- RCOL with custom chunks, DWORD-aligned, lots of `0xDEADBEEF` filler ("serialization sentinel"). Hashes can be
  looked up in the package `_KEY` (0x0166038C). Processed by the SACS engine.

## Definition chunks
- `S_SM` v0x202: Name hash (usually file name without path/extension); lists of S_AD (actors), S_PD (properties),
  S_St (states) indices; then a list of **actor aliases** `{filename hash (source file with extension), actor hash in
  the animation, actor hash in the jazz script}` (this is the binary of `Assign Actor "x.ma"."x" as "x"`); DEADBEEF;
  Properties; Priority ("automation priority"); Overlay (ThoughtBubble, OverlayFace, OverlayHead, OverlayBothArms,
  OverlayUpperbody, OverlayNone, Unset = 0..6); 4 empty DWORDs.
- `S_St` v0x101: name hash, Flags, S_DG index, transitions (S_St indices), Overlay override.
- `S_PD` v0x100: name hash, default value hash. `S_AD` v0x100: name hash, empty DWORD.
- `S_DG` v0x101: blank, all descendant DGN indices, root DGN indices, DEADBEEF.

## Decision graph nodes (each ends `/DGN`)
- `SoPn` v0x101 select on parameter: param index, cases {value hash, DGN list}, DEADBEEF.
- `SNSN` v0x101 next state: S_St index.
- `Rand` v0x101: outcomes {FLOAT weight, DGN list}, DEADBEEF, flags.
- `Play` v0x105: CLIP TGI, TkMk TGI; count1 entries of 4 DWORDs `{Empty, Empty, Actor hash, Slot hash}` ("only one
  instance of this in jazzdata.package"); count2 entries `{actor hash, IkSuffix parameter hash}`; DEADBEEF; additive
  CLIP TGI; UTF-16 animation name (len DWORD, null terminated, padded to DWORD; len 0 = no data at all); additive name
  likewise; DEADBEEF; Flags; Priority; FLOAT 0; blend-in seconds; blend-out seconds; FLOAT 0; Speed (1.0); S_AD index of
  the animated actor; Priority again; DWORD always 16; 5 empty; DEADBEEF; multicast footer (DGN list, "on animation
  complete?").
- When the name string is set, the CLIP and TkMk refs are `00000000:00000000:6b20c4f302d5df12` and the string is
  hashed (after parameter substitution) to get the clip id.
- `Prop` v0x100: S_AD index of the prop actor, S_PD index, catalog ref `QWORD instance, DWORD type, DWORD group (0)`;
  type is 0x139F7591 (CatalogObjectResourceID, exists in no package), changed internally to 0x02DC343F before
  instantiation; 4 unused DWORDs; multicast footer.
- `AcOp` v0x100: actor index, operation (0 none, 1 SetMirror), operand (bool), 3 blank, footer.
- `Stop` v0x104: same tail as Play (flags, priority, blends, speed, actor, ...), footer.

## Notes and contradictions
- **Play count1 entry**: wiki = `{Empty, Empty, Actor, Slot}`; s3pi-wrappers `ActorSlot` = `{chainId, slotId,
  actorHash, slotHash}` (s3pi-wrappers `JazzGraph`, https://github.com/ChaosMageX/s3pi-wrappers). The first two DWORDs are probably chain/slot ids that
  were zero in the one EA sample the wiki authors saw. Not verified.
- The page has **no flag table** for Play/Stop flags; the conflicting tables are in `topics/jazz.md`.
- XSauroxPlayer's tools copy EA Jazz machines byte for byte, so these layouts were never checked by writing
  them by hand.
