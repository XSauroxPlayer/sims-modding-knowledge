# TS3 OBJK (0x02DC343F) - object components

"Identifies what kind of object this is and what its behaviour is." Analysis credited to atavera.

## Layout
`DWORD version (7)`, `DWORD TGI_offset`, `DWORD TGI_size` (key table at the end), `BYTE count1` component ids
(FNV32 of the component name), `BYTE count2` component data entries `{DWORD len, STRING key, BYTE type, data}`,
`BYTE VisibilityFlag` (0 VisibleAlways, 1 VisibleInToolsOnly, 2 VisibleAsDistantTerrain), TGI block list.

## Components
| id | name | note |
|---|---|---|
| 0x1A8FEB14 | Physics | always, except plants |
| 0x22706EFA | Sim | object is a Sim (`simOutfitKey` optional) |
| 0x23177498 | Script | `scriptClass` required |
| 0x2954E734 | Model | `modelKey` required (VPXY) |
| 0x3AE9A8E7 | Sacs | object can have SACS/Jazz scripts ("does not include being used as a prop") |
| 0x461922C8 | Location | object can have its own location (not only attached to others) |
| 0x54CB7EBB | Transform | always |
| 0x61BD317C | Steering | moves on its own; `steeringInstance` Car/Bicycle/Sim |
| 0x6693C8B3 | LotObject | always |
| 0xC602CD31 | Tree | modelKey -> SPT |
| 0xC807312A | Footprint | `footprintKey` (only if modelKey is not a VPXY) |
| 0xEE17C6AD | Animation | object itself can be animated (being carried by an animated object does not count) |
| 0x2EF1E401 Slot, 0x50B3D17C VisualState, 0x80D91E9E Effect, 0xDA6C50FD Lighting | | unused |

Data types: 0 String, 1 ResourceKey (index into TGI list), 2 AssetResourceName (index), 3 SteeringInstance (string),
4 UInt32. Keys: `allowObjectHiding` (presence = object hides the selected Sim from the camera), `footprintKey`,
`modelKey`, `scriptClass`, `simOutfitKey`, `steeringInstance`.

## Relevance
- Animated converted objects need the **Animation** and **Sacs** components; walking creatures also
  touch Steering/Location. The script class rule ("starts with `Sims3.`") is in `sources/nonasims/`.
