# TS3 BOND / Slot Adjust (0x0355E0A6)

- RCOL chunk **without** a 4-byte tag. "Tweaks the position, scale, and orientation of slots/bones per outfit."
- Layout: `DWORD version`, `DWORD count`, then per entry `DWORD slot/bone name hash`, `FLOAT offset X Y Z`,
  `FLOAT scale X Y Z`, `FLOAT quat X Y Z W`.

## Relevance
- This is where per-outfit slot offsets live; modders suspect the default `slotOffset` values used by IK come from
  BOND/rig defaults (MTS t=629522). The binary analysis (`research/ts3-native-ik.md`) composes
  slotOffset once after the weighted target average; BOND values were not part of that measurement.
  See `topics/ik-and-slots.md`.
