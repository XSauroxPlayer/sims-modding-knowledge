# TS3 S3SA signed assembly (0x073FAA07)

- "Signed assemblies, encrypted .NET assemblies. They function as the game scripts." EA ones live in
  gameplay.package, scripts.package, simcore.package; custom packages may carry their own, loaded when referenced.
- **No piecemeal overrides**: a core/global script mod must replace the whole assembly, so only one creator's
  override per assembly can be installed at a time (wiki note dated 2009; still the community rule).
- Layout: `BYTE version` (1 pre-EP2, 2 from EP2), if v>=2 `DWORD len` + UTF-16 game version (from
  `Game/bin/code_version.txt`), `DWORD checksum_typeid 0x2BC4F79F`, `BYTE[64] checksum`, `WORD block_count`,
  `QWORD[block_count]` decryption table, `block_count*512` bytes of data.
- Decryption: seed = sum of table QWORDs masked to `table length - 1`; for each table entry with bit 0 set write 512
  zero bytes, else XOR each byte with `table[seed]` and set `seed = (seed + original byte) % table length`.
- Since EP2 / the June 2010 patch the signature is not checked: checksum can be anything and the decryption table can be
  all zeros (data stored in clear). Before that a `d3dx9_31.dll` wrapper in `Game\Bin` disabled validation.
- Decrypted content is a plain CLR assembly.

## Relevance
- A core mod replaces a whole game DLL. For new objects a separate S3SA in the mod's own package is enough.
