# TS3 OBJD (0x319E4F1D)

Price, buy/build sort flags and links to other resources. Long page (field list plus large flag tables); summary of
the parts useful for object conversion. Raw wikitext: https://simswiki.info/index.php?title=Sims_3:0x319E4F1D&action=raw

## Layout (version-gated)
Version, TGI offset/size; Catalog Resource **Material List** and (v>=0x16) InstanceName; Catalog **Common** block;
OBJK index; ObjectTypeFlags (+ ObjectTypeFlags2 if v>=0x1A); WallPlacementFlags; MovementFlags; wall cutout tiles per
level; levels; wall masks; `BYTE ScriptEnabled`; diagonal OBJD index; AmbienceType hash; RoomFlags;
FunctionCategoryFlags; SubCategory1 (QWORD) (+SubCategory2 if v>=0x1C); SubRoomFlags; BuildCategoryFlags; cutout DDS;
floor cutout fields (v>=0x17..0x21); BuildableShellDisplayState hashes (v>=0x18); LevelBelow/Proxy OBJD,
BlueprintXML/Icon (v>=0x19..0x1F); **slotPlacementFlags**; SurfaceType and SourceMaterial (7-bit strings);
Moodlet given + score; 5 topic/rating pairs; fallback OBJD (used when loaded in too early an EP); modular arch models
(v>=0x22); TGI list.

## Useful tables
- ObjectTypeFlags: 0x2 AutomaticallyBuyAnotherAfterPlacing, 0x8 IsDoor, 0x80 RabbitHole, 0x200 ForceToFullGrid,
  0x8000 TakeParentAlongWhenPicked, 0x10000 LiveDraggingEnabled, 0x20000 AllowOnSlope, 0x40000 LargeObject,
  0x80000 FloatsOnWater, ... ObjectTypeFlags2: 0x20 MustFaceCardinalDirection, 0x40 IsRug, 0x80 IsGiftable, ...
- slotPlacementFlags (which slots the object fits into): 0x8 Small, 0x10 Medium, 0x20 Large, 0x100 Sim, 0x200 Chair,
  0x400 CounterSink, 0x800 EndTable, 0x1000 Stool, 0x2000 CounterAppliance, 0x4000 PlanterBowl, 0x40000 Functional,
  0x80000 Decorative, 0x800000 KeepAtSeaLevel, 0x1000000 Upgrade, 0x2000000 Vertical, 0x4000000 PlacementOnly,
  0x10000000 CardinalRotation, 0x20000000 FullRotation, 0x40000000 AlwaysUp.
- Moodlet given: 1 Comfy (seating), 2 Well Rested (beds), 3 Enjoys Music; score 1-3 = strength.
- Topic/rating pairs (catalog stat lines): 1 Environment, 2 Hunger ... 0x10 Upgradable, 0x17 Never Breaks,
  0x18 Portable ...; rating 1-10 "Logic: 10", 0xB = "+ Logic"; topic 0 stops the list.
- World Editor / CAW catalog: Common block version 0xE, `Unknown7[3]` (IsVisibleInWorldBuilder) = 1, BuildCategory
  0x1000 Tree / 0x2000 Rock / 0x8000 misc.

## Relevance
- Catalog stat lines (topic/rating) are how a TS2 reward's "Never breaks"/skill tags show in TS3's catalog.
- slotPlacementFlags decide whether a converted deco object can go on tables/counters.
