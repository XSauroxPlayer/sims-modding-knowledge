# TS3 RSLT (0xD3044521)

RCOL chunk `'RSLT'`, Version, then five counts: route, containment, effect, **IK targets**, cone slots.
For each group: `count` slot name FNV32s, `count` bone name FNV32s (bones of the object rig), (containment only:
`count` DWORD flags = slot placement flags), `count` 4x3 matrices (12 floats); cones add `{radius, angle (rad)}` per
slot; if the group is non-empty, `numSlotsWithOffsets` entries `{slot index, FLOAT[3] position, FLOAT[3] euler
rotation (rad)}`.

## Against verified findings (EA game files, checked by XSauroxPlayer)
- Agrees on the order and fields (sample: RSLT version 4, offsets count 0 in the EA objects taken). The checks add:
  EA names `RoutingSlot_<i>`, `ContainmentSlot_<i>`, `FXJoint_<i>`; bone hash = FNV32 of the lowercase RIG bone name;
  the matrix is the bone's bind pose **in object space** (not identity); s3py's RSLT writer is broken.
- **Minor contradiction**: the OBJD slot flag table labels 0x1 "None", but every EA seat containment slot checked
  has flag 0x1 (DeltaBuild0 chairs and sofas). So 0x1 is not "no flags" in RSLT containment slots; meaning unclear.
- IK target slots in RSLT are the object-side ends of CLIP IK targets (see `topics/ik-and-slots.md`).
